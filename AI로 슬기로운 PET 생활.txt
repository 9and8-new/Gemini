# 🍌나노 바나나란? => 별명임. 구글에서 새로운걸 개발할때 과일이름으로 많이 별명을 만듬.
- 구글 DeepMind / Gemini 팀이 개발한 **최신 이미지 편집 / 생성 모델** 업데이트 이름이다. (별칭 개념)
- 정식 이름은 models/**gemini-2.5-flash-image-preview**
- 기존의 Gemini 이미지 기능을 업그레이드한 버전 중 하나로, 이미지의 **(특징)일관성 유지**, **(특징)자연스러운 편집**, **(특징)장면 보존** 능력에 초점을 둔다.
- “한 장의 사진을 여러 방향으로 변형하되, 원래 특징(얼굴, 배경 톤 등)을 많이 잃지 않게” 만드는 게 이 모델의 강점
- 최근에는 **제미나이**에서 바로 채팅으로 실행가능하다.
- 한글도 가능하지만, **영어**로 프롬프트를 입력하는 것이 퀄리티가 뛰어나다.

기능							설명
캐릭터 일관성 (Likeness preservation)		얼굴이나 캐릭터 특징을 바꾸지 않으면서 의상, 배경, 스타일만 바꾸는 편집 가능 
장면 보존 / 블렌딩				원본 배경이나 주변 요소와 잘 어우러지게 편집 — 배경 변경해도 어색하지 않게 유지 
다중 이미지 합성				두 개 이상의 사진을 합성해서 하나의 씬으로 만드는 작업 가능
편집 반복 / 다중 턴 (multi-turn editing)	한 번 편집한 뒤 그 결과를 기반으로 다시 편집 지시 가능 — 연속적인 편집 흐름 유지됨
스타일 전환 / 리믹스			한 이미지의 스타일(색감, 질감 등)을 다른 이미지 객체에 적용 가능

퀄리티가 떨어지면 새로운 채팅으로 새롭게 시작하는것도 방법.

GPT에 영어로 번역요청해도됨. => 나노바나나에 입력목적이다. 라고 말하면 더 알맞게끔 AI가 바꿔줌

네거티브: 텍스트 없음, 워터마크 없음, 로고 없음, 브랜드 없음, 저작권 캐릭터, 시리즈 IP, 상표 디자인, 레진, PVC, 실체 조각상, 불투명 표면, 장난감 같은 광택, 광선, 스캔 라인, 점, 왜곡, 불필요한 숫자 없음.
